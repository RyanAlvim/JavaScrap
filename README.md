# ☕ JavaScrap

> **Web Scraper desenvolvido em Java utilizando Selenium para extração automatizada de informações do site ZapGráfica.**

---

## 📌 Sobre o projeto

O **JavaScrap** é um projeto desenvolvido em **Java** com o objetivo de automatizar a coleta de informações disponibilizadas no site **ZapGráfica**.

A aplicação utiliza o **Selenium WebDriver** para acessar e navegar pelo site, localizar os elementos necessários e extrair os dados de forma automatizada.

O projeto foi desenvolvido como uma aplicação prática de conceitos de:

* 🌐 Automação de navegadores
* 🔎 Web Scraping
* ☕ Desenvolvimento em Java
* 🤖 Automação de tarefas repetitivas
* 🌳 Manipulação e extração de dados de páginas web

## 🎯 Objetivo

O principal objetivo do **JavaScrap** é demonstrar como o **Java pode ser utilizado para automatizar a interação com páginas web e realizar coleta estruturada de informações**.

Além da finalidade prática, o projeto serve como estudo de **Selenium, automação web e manipulação de dados obtidos através de páginas HTML**.

---

## 🚀 Como executar

### Pré-requisitos

Antes de executar o projeto, é necessário possuir:

* **Java** instalado
* **Selenium WebDriver**
* Um navegador compatível com o WebDriver utilizado pelo projeto

### Execução

Clone o repositório:

```bash
git clone https://github.com/RyanAlvim/JavaScrap.git
```

Entre no diretório:

```bash
cd JavaScrap
```

Depois, execute o projeto utilizando a configuração de build utilizada pelo repositório.
